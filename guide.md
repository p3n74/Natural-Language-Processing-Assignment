Project Guideline:
1. Problem Definition
Clearly define an NLP problem you chose (e.g., sentiment analysis, text classification, topic
modeling, intent detection, text similarity, etc.)
Justify why the problem is relevant.
Define:
o Input data
o Output prediction
o Evaluation metric
2. Data Collection
Students may:
• Collect their own data (survey with open-ended text)
• Use publicly available datasets
• Scrape small-scale public text
Requirements:
• Minimum 100 text samples (recommended for supervised tasks)
• Balanced dataset (if classification)
• Proper citation of data source
3. Text Preprocessing
Should include:
• Tokenization
• Lowercasing
• Stopword removal
• Stemming or lemmatization
• Handling punctuation and special characters
Students should explain:
• Why preprocessing choices were made
• Impact on results (if tested)
4. Feature Engineering
At least ONE of these methods:
• Bag-of-Words
• TF-IDF
• Word embeddings (Word2Vec / GloVe / pretrained embeddings)
• N-grams
5. Model Development
Students must implement:
• At least one (1) machine learning model
(e.g., Logistic Regression, Naive Bayes, SVM, Random Forest)
• Train-test split or cross-validation
• Hyperparameter explanation (basic level)
3
6. Evaluation and Analysis
Must include:
• Accuracy
• Precision
• Recall
• F1-score
• Confusion matrix
Very important:
• Error analysis (analyze misclassified examples)
7. Conclusions
Students must:
• Summarize findings
• Compare models
• Discuss any limitations
• Suggest improvements
• Reflect on challenges faced
